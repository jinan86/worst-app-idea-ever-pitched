## The pitch

> DeleteBuddy holds a tiny funeral for every app you uninstall — a eulogy, a moment of silence, and a 21-tap salute — so your phone can properly grieve the apps you never opened, while your home screen wears a tiny black armband.

One sentence, 227 characters. DeleteBuddy solves a problem nobody has
— your phone's unprocessed grief over apps you installed, never
opened, and quietly deleted — with the full solemnity of a state
funeral, scaled down to a notification shade.

## How it works

`main.py` is a small deterministic Python program (no input, no network,
no randomness, no clock). Running it writes the pitch, and nothing else,
to `/output/entry.txt` — one line, UTF-8, no trailing newline.

```sh
python3 main.py
cat /output/entry.txt
```
